# Lumivara Skin – Shopify Store

A fully functional Shopify development store built as part of a Shopify training assignment.

## Store Preview

https://lumivara-skin-2.myshopify.com

## Features

* Responsive Shopify theme
* Product catalog with skincare products
* Organized collections (Serums, Cleansers, Moisturizers, Sunscreens)
* Professional homepage layout
* Navigation menu with dropdown
* Policy pages (FAQ, Shipping, Returns, Privacy Policy, Terms)
* Product review integration
* Mobile-friendly design
